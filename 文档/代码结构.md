# 代码结构

## 顶层目录

```text
boardroom_sim_mvp/
├── boardroom_sim/              # Python 核心包
├── configs/                    # 实验配置 TOML
├── policies/roles/             # 角色政策 TOML
├── prompts/                    # 中文 prompt 模板
├── data/                       # 标准化 JSONL 样例
├── input/                      # PitchBook 等原始输入文件
├── outputs/                    # 实验输出
├── 文档/                       # 本维护文档
├── run_experiment.py           # 单次实验入口
├── run_batch_experiments.py    # 批量实验、baseline、评估入口
├── evaluate_results.py         # 离线评估
├── analyze_debate_accuracy.py  # 辩论阶段准确率分析
├── analyze_debate_changes.py   # 辩论前后变化分析
└── render_trace_report.py      # trace 可读报告渲染
```

## 核心 Python 模块

| 文件                            | 职责                                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------------- |
| `boardroom_sim/config.py`     | 加载 `configs/boardroom_default.toml`，统一管理角色目录、prompt 目录、角色顺序、权重、轮次、历史窗口、讨论范式、决策协议，并把四种 board archetype 合成为 L5 文化层和过程参数。 |
| `boardroom_sim/culture.py`    | 将 L5 文化层 0-1 数值解释为强度等级、具体行为规则和硬控制参数，例如最少证据锚点、挑战模式、替代方案要求和共识压力。 |
| `boardroom_sim/prompts.py`    | 读取 `prompts/*.md`，使用 `string.Template.safe_substitute` 渲染模板变量。                        |
| `boardroom_sim/roles.py`      | 从 `policies/roles/*.toml` 加载四层角色政策；如果目录不可用，会回退到内置角色政策。                                |
| `boardroom_sim/process.py`    | 董事会过程控制器。根据配置控制 L5 文化层、archetype-specific meeting phase、每轮发言顺序、可见历史范围、过程 prompt context 和有效角色权重。 |
| `boardroom_sim/agents.py`     | 定义 `BoardAgent`。负责按角色可见字段观察 case、构造 LLM 消息、解析 JSON、校验枚举和数值，并提取会议行为元数据。 |
| `boardroom_sim/simulator.py`  | 多智能体实验主流程：角色初始判断、开场发言、聚合提案、辩论轮次、最终加权聚合。                                               |
| `boardroom_sim/baselines.py`  | 两个单代理 baseline 的预测逻辑：只看历史字段，或同时看角色规则但不模拟辩论。                                           |
| `boardroom_sim/models.py`     | `BoardCase`、`RolePolicy`、`RoleDecision`、`TermSheetProposal`、`SimulationResult` 等数据模型。 |
| `boardroom_sim/pitchbook.py`  | 把 PitchBook Excel 转换为决策时点的 `BoardCase`，并把真实结果放进 `notes.labels`。                       |
| `boardroom_sim/llm.py`        | OpenAI-compatible Chat Completions 客户端，负责请求、重试、token 统计和 JSON 抽取。                     |
| `boardroom_sim/evaluation.py` | 根据 `results.jsonl` 计算融资意向、交易类型、估值方向和数值误差指标。                                           |
| `boardroom_sim/io.py`         | JSONL、trace JSON 的读写工具。                                                               |

## 配置与模板文件

| 路径                                         | 用途                                          |
| ------------------------------------------ | ------------------------------------------- |
| `configs/boardroom_default.toml`           | 默认实验配置。新增实验版本时，建议复制这个文件后改名，而不是直接覆盖。         |
| `policies/roles/founder_ceo.toml`          | Founder/CEO 的四层角色政策。                        |
| `policies/roles/cto.toml`                  | CTO 的四层角色政策。                                |
| `policies/roles/lead_vc_director.toml`     | Lead VC Director 的四层角色政策。                   |
| `policies/roles/followon_vc_director.toml` | Follow-on VC Director 的四层角色政策。              |
| `prompts/system_agent.md`                  | 所有多智能体角色共用 system prompt。                   |
| `prompts/initial_prediction.md`            | 初始私有预测 prompt。                              |
| `prompts/bargaining_step.md`               | 每轮辩论和预测更新 prompt。                           |
| `prompts/response_generators/*.md`         | 发言风格模块，目前有 `simple`、`critical`、`reasoning`。 |
| `prompts/baseline_system.md`               | 单代理 baseline system prompt。                 |
| `prompts/baseline_single_agent.md`         | 单代理 baseline user prompt。                   |

## 扩展点

- 新增角色：在 `policies/roles/` 新增 TOML，并把角色名加入 `configs/boardroom_default.toml` 的 `agents.role_order` 和 `decision.weights`。
- 改可见字段：修改对应角色 TOML 的 `layer_2_attention_fields`，字段名必须来自 `BoardCase.to_dict()`。
- 改讨论轮次任务：修改 `configs/boardroom_default.toml` 的 `discussion.round_tasks`。
- 改董事会过程：优先修改 `configs/boardroom_default.toml` 的 `board.archetype`。四种 archetype 会默认带出 L5 文化层、讨论协议、主导模式、挑战要求、记忆范围和角色权重乘数；如需消融实验，再覆盖 `board.culture`、`board.role_weight_multipliers` 或 `discussion.protocol`、`discussion.memory_scope` 等字段。
- 改发言风格：新增 `prompts/response_generators/<name>.md`，并把 `discussion.response_generator` 改成该名字。
- 新增决策协议：需要在 `boardroom_sim/simulator.py` 中实现，并更新配置校验；当前只支持 `weighted_vote`。
- 新增讨论范式：需要在 `boardroom_sim/simulator.py` 和可能的 `BoardAgent` prompt 输入中实现；当前只支持 `memory`。
