# 实验运行指南

## 环境要求

- Python 3.11 或更高版本。
- 一个 OpenAI-compatible Chat Completions API。
- API key 通过环境变量或命令行传入，不要写进代码。

安装依赖：

```bash
python -m pip install -r requirements.txt
```

当前实验运行依赖很少：`pandas` 用于读取和处理 PitchBook 表格，`openpyxl` 用于让 `pandas.read_excel()` 读取 `.xlsx/.xlsm` 工作簿。LLM 请求使用 Python 标准库 `urllib`，不需要额外安装 OpenAI SDK。

默认模型配置仍可通过命令行覆盖。代码会读取：

- `BOARDROOM_LLM_API_KEY`
- `BOARDROOM_LLM_MODEL`
- `BOARDROOM_LLM_BASE_URL`
- `BOARDROOM_LLM_TEMPERATURE`
- `BOARDROOM_LLM_TIMEOUT_SECONDS`
- `BOARDROOM_LLM_HTTP_MAX_RETRIES`
- `BOARDROOM_LLM_RETRY_BASE_SECONDS`

## 单次实验

```bash
python run_experiment.py \
  --input data/sample_cases.jsonl \
  --output outputs/sample_results.jsonl \
  --trace-output outputs/sample_traces.json \
  --config configs/boardroom_default.toml \
  --case-limit 3
```

如果使用 PitchBook Excel：

```bash
python run_experiment.py \
  --input input\260524_02_03_pitchbook_sample_100_shared.xlsx \
  --output outputs/pitchbook_results.jsonl \
  --trace-output outputs/pitchbook_traces.json \
  --config configs/boardroom_default.toml \
  --case-limit 3
```

常用覆盖参数：

```bash
--bargaining-rounds 1
--history-limit 3
--model glm-4.7-flash
--base-url https://api.z.ai/api/paas/v4
--temperature 0.2
```

## 批量实验

```bash
python run_batch_experiments.py \
  --input input/260524_02_03_pitchbook_sample_100_shared.xlsx \
  --output-dir outputs/batch/smoke_test \
  --config configs/boardroom_default.toml \
  --repeats 1 \
  --case-limit 5
```

批量运行会自动生成：

- 每个 run 的 `results.jsonl`
- 每个 run 的 `traces.json`
- 每个 run 的 `metrics.json`
- 每个 run 的 `case_metrics.csv`
- 每个 run 的 `debate_accuracy_report.md`
- 每个 run 的两个 baseline 结果和指标
- 总体 `aggregate_metrics.json`
- 总体 `case_metrics.csv`

中断后恢复：

```bash
python run_batch_experiments.py \
  --input input\260524_02_03_pitchbook_sample_100_shared.xlsx \
  --output-dir outputs/batch/smoke_test \
  --config configs/boardroom_default.toml \
  --resume
```

跳过详细 trace：

```bash
--skip-traces
```

跳过 baseline：

```bash
--skip-baselines
```

## 离线评估

python evaluate_results.py \

  --case-metrics-output outputs/pitchbook_case_metrics.csv

## 辩论变化分析

分析辩论前后预测如何变化：

```bash
python analyze_debate_changes.py \
  --input outputs/batch/smoke_test/run_001/traces.json \
  --output outputs/batch/smoke_test/run_001/debate_changes_report.md \
  --case-csv-output outputs/batch/smoke_test/run_001/debate_changes_cases.csv
```

分析每轮辩论是否让预测更接近真实标签：

```bash
python analyze_debate_accuracy.py \
  --input outputs/batch/smoke_test/run_001/traces.json \
  --output outputs/batch/smoke_test/run_001/debate_accuracy_report.md \
  --case-csv-output outputs/batch/smoke_test/run_001/debate_accuracy_cases.csv \
  --baseline-results baseline_history_only=outputs/batch/smoke_test/run_001/baseline_history_only_results.jsonl \
  --baseline-results baseline_history_with_roles=outputs/batch/smoke_test/run_001/baseline_history_with_roles_results.jsonl \
  --deal-size-tolerance 0.50
```

## 新建一个实验配置

建议复制默认配置：

```bash
copy configs\boardroom_default.toml configs\my_experiment.toml
```

然后修改：

```toml
[experiment]
name = "my_experiment"
bargaining_rounds = 2
history_limit = 5

[discussion]
protocol = "chair_gated"
memory_scope = "full"
response_generator = "reasoning"
round_tasks = [
  "第 1 轮：只讨论交易类型和融资规模。",
  "第 2 轮：只讨论估值方向和投资人持股比例。",
]

[decision.weights]
Founder_CEO = 2.0
CTO = 0.5
Lead_VC_Director = 3.0
Followon_VC_Director = 1.5
```

运行时指定：

```bash
python run_batch_experiments.py \
  --input input/260524_02_03_pitchbook_sample_100_shared.xlsx \
  --output-dir outputs/batch/my_experiment \
  --config configs/my_experiment.toml \
  --repeats 1
```

## 配置董事会过程

优先只改 `board.archetype`：

```toml
[board]
archetype = "value_creating"
```

四种 archetype 会默认带出 L5 文化层、讨论协议、主导模式、挑战要求、记忆范围和角色权重乘数：

| archetype        | 文化/过程含义                | 默认过程效果                                           |
| ---------------- | ---------------------------- | ------------------------------------------------------ |
| `aunt`           | 形式化、被动确认、管理层主导 | `rubber_stamp`，低挑战，有限记忆，Founder CEO 权重更高 |
| `barbarian`      | 控制、监督、低信任、高批判   | `top3_dominance`，强制挑战，Lead VC 权重更高           |
| `clan`           | 高亲近、高信任、重共识       | `chair_gated`，不强制挑战，Founder CEO 权重略高        |
| `value_creating` | 监督和支持并重，开放异议     | `free_interjection`，强制建设性挑战，权重保持均衡      |

如需做消融实验，可以只覆盖某些字段：

```toml
[board]
archetype = "value_creating"

[board.culture]
criticality = 0.75
creativity = 0.70
cohesiveness = 0.70
openness_generosity = 0.80
preparation_involvement = 0.85

[board.role_weight_multipliers]
Founder_CEO = 1.0
CTO = 1.0
Lead_VC_Director = 1.0
Followon_VC_Director = 1.0

[discussion]
protocol = "chair_gated"
challenge_required = true
memory_scope = "full"
memory_window = 10
```

当前 `protocol` 支持：

- `chair_gated`：固定顺序发言。
- `free_interjection`：每轮轮换顺序，模拟开放插话。
- `top3_dominance`：有效权重最高的前三位角色发言。
- `rubber_stamp`：第一轮只让 Founder CEO 和 Lead VC 短讨论，后续轮次无人发言。

当前 `archetype` 支持：

- `value_creating`
- `aunt`
- `barbarian`，兼容旧别名 `barbarian_control`
- `clan`，兼容旧别名 `clan_consensus`

`archetype` 会改变 L5 文化层、讨论过程和角色有效权重。trace 中会记录 `board_process`、`base_role_weights` 和 `effective_role_weights`。

## 常见修改

### 改角色可见字段

修改对应文件：

```text
policies/roles/founder_ceo.toml
policies/roles/cto.toml
policies/roles/lead_vc_director.toml
policies/roles/followon_vc_director.toml
```

字段在：

```toml
layer_2_attention_fields = [
  "prior_deal_size_usd_m",
  "employee_growth_rate",
]
```

字段名必须来自 `BoardCase.to_dict()`。不要加入真实标签字段。

### 改每轮讨论流程

修改配置：

```toml
[discussion]
round_tasks = [
  "第 1 轮：...",
  "第 2 轮：...",
]
```

`bargaining_rounds` 如果大于 `round_tasks` 数量，后续轮次会复用最后一条任务。

### 改 prompt 文案

直接修改：

```text
prompts/system_agent.md
prompts/initial_prediction.md
prompts/bargaining_step.md
prompts/baseline_system.md
prompts/baseline_single_agent.md
```

注意不要删除模板变量，例如 `$observed_fields_json`、`$proposal_json`。

### 新增发言风格

新建：

```text
prompts/response_generators/my_style.md
```

配置：

```toml
[discussion]
response_generator = "my_style"
```

## 快速验证

修改配置、角色或 prompt 后，建议先跑不写 `.pyc` 的静态检查：

```bash
python -B -c "from pathlib import Path; files=list(Path('boardroom_sim').glob('*.py'))+[Path('run_experiment.py'),Path('run_batch_experiments.py')]; [compile(path.read_text(encoding='utf-8'), str(path), 'exec') for path in files]; print('ok')"
```

验证配置和角色加载：

```bash
python -B -c "from pathlib import Path; from boardroom_sim.config import load_experiment_config; from boardroom_sim.roles import build_role_policies; c=load_experiment_config(Path('configs/boardroom_default.toml')); print(c.name, c.bargaining_rounds, c.history_limit); print(list(build_role_policies(c.role_policy_dir, c.role_order)))"
```

验证 prompt 渲染：

```bash
python -B -c "from boardroom_sim.config import load_experiment_config; from boardroom_sim.prompts import PromptRenderer; c=load_experiment_config(); r=PromptRenderer(c.prompts_dir, c.response_generator); print(r.render('system_agent', role_name='Founder_CEO', role_policy_json='{}')[:120])"
```
