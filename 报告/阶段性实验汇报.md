# 董事会多智能体模拟实验阶段性汇报
 
本文简要汇报当前董事会多智能体模拟实验的阶段性进展、初步结果、现存问题和下一步改进方向。
 
## 一、当前实验进度
 
当前实验推进到一个可以读取 PitchBook 表格、调用大模型、生成多角色董事会辩论过程和结构化结果的**最小**可运行版本。
 
**已经实现的主要功能**
 
1. 现实数据驱动输入
 
- 代码从  02_03_pitchbook_sample_100_shared.xlsx  中读取案例
- 第一版只筛选有 postvaluation 的正样本 VC 交易
- 每个案例会被转换成统一的  BoardCase ，供后续 Agent 使用
 
2. 真实结果字段隐藏
 
- 当前目标交易的真实结果不会发送给 Agent
- 真实融资是否发生、真实融资额、真实交易类型、真实估值方向、CEO 更换标签等字段保存在  notes.labels  中，仅用于后续评测
 
3. 四类董事会角色建模
 
- 已实现四个角色：
- Founder_CEO
- CTO
- Lead_VC_Director
- Followon_VC_Director
- 每个角色都有四层规则：
- L1 目标函数
- L2 可见字段
- L3 启发式判断规则
- L4 互动协议
 
4. 角色信息隔离
 
- 不同角色只能看到自己 L2 层中允许关注的字段
- 例如：CEO 更关注控制权、历史融资、董事会结构；CTO 更关注员工、技术团队、行业和产品描述；VC 更关注估值、融资历史、投资人结构和保护条款
 
5. LLM 决策与辩论流程
 
- 每个角色先根据自身可见字段做初始判断
- 随后进入多轮辩论
- 每轮辩论中，角色会看到当前综合提案、其他角色最新立场和历史发言，并可以更新自己的判断
 
6. 结构化输出
 
- 将模拟过程输出至json文件
 
7. 缺失值处理
 
- 表格中缺失的数值保留为 JSON null
- Prompt 中明确说明：null 表示缺失或未观测，不能当作 0
- 避免模型把缺失的 post-money valuation、员工数、投资人偏好等字段误认为真实为 0（否则大大影响模型判断）
 
8. Prompt 与输出字段调整
 
- 当前输出聚焦：
- 是否现在融资： financing_intent 
- 交易完成可能性： completion_view 
- 预测融资额： predicted_deal_size_usd_m 
- 预测交易类型： predicted_deal_type 
- 估值方向： valuation_direction 
- CEO 更换观点： ceo_replacement_view 
-  completion_view  为二分类： likely_complete  /  unlikely_complete （是否可能完成交易）
-  valuation_direction  为三分类： up  /  flat  /  down （上升/持平/下降）
 
## 二、初步看到的结果
 
目前单案例实验已完整跑通，能够生成如下过程：
 
1. 共同背景信息
2. 四个角色的初始判断
3. 每轮辩论中每个角色的发言
4. 每轮后更新的综合提案
5. 最终聚合结果
6. 模拟结果与真实结果之间的相似度对比
 
从已有运行结果看，实验已能产生具有角色差异的推理过程：
 
- CEO：从公司融资历史、创始人控制权、董事会结构角度判断是否融资
- CTO：从技术团队、行业资本需求、研发扩张角度支持或反对融资
- Lead VC：更关注定价纪律、下行保护、退出倍数和条款强度
- Follow-on VC：更关注跟投、pro-rata 权利和避免被稀释
 
已有单案例结果显示，模型能够判断公司倾向于继续融资，并形成多轮讨论，但也暴露出一些问题：
 
- 预测融资额明显低于真实融资额
- CEO 更换判断没有命中真实标签（目前对这一部分相关预测个人理解还不够）
- 部分角色在多轮辩论后的立场变化不大（调用的大模型能力不够强/当前提示词让大模型只生成较短的辩论信息/当前提示词中对大模型修改个人立场的规则不够完善）
 
## 三、当前存在的问题
 
1. 数据缺失仍然明显

PitchBook 表格中很多关键字段可能缺失，例如：prior post-money valuation、prior pre-money valuation、investor ownership、employee count、lead investor preferred deal size、lead investor preferred valuation。Agent 不会误读为 0，但会因信息不足给出保守、模板化或偏小的预测。

2. 当前主要是正样本实验

第一版只关注真实发生的 VC 交易，所有样本本质上都是“确实发生融资”的正样本，难以严格评测“是否应该发起融资”判断，缺少无融资对照样本。当前更适合评测：
 
- 融资额预测是否接近真实值
- 交易类型是否接近真实类型
- 估值方向是否接近真实方向
- CEO 更换压力是否接近后续真实变化
 
3. 辩论机制还比较浅

每轮辩论后角色可更新判断，但更新幅度有限，可能原因：
 
- prompt 对“什么情况下应该改变立场”约束不够强
- 满意度分数没有强制与对方让步、条款变化、风险缓解挂钩
- 综合提案较简单，无法充分推动实质性谈判
 

4. CEO 更换不清晰

与 CEO 更换相关的字段还需进行调研和修正
 
5. 评测指标还需要完善
当前相似度计算为初步版本，后续要进行优化。
 
## 四、下一步改进方向
 
1. 增强融资额预测逻辑（重点）
 
- 在 prompt 中进一步说明如何根据历史融资额、累计融资额、公司年龄、行业资本密集度估算融资额
- 增加**规则基准值**（是否可行？）供 LLM 参考
 
2. 增强角色立场变化机制
 
- 要求角色说明是否被其他角色说服
- 要求满意度变化必须对应具体条款变化
- 让综合提案每轮后更明确体现妥协
 
3. 扩展评测脚本
 
- 批量统计融资额误差
- 统计交易类型准确率
- 统计估值方向准确率
- 统计 CEO 更换标签准确率
- 输出总体结果表和错误案例清单
 
4. 加入负样本或伪负样本
 
- 若要评测“是否发起融资”，需构造无融资发生的公司时点作为对照
- 否则当前实验只能评测正样本中的交易规模、类型、估值方向和治理结果
 
## 五、阶段性结论
 
当前实验已完成从 PitchBook 数据到多智能体董事会模拟的基本闭环：
PitchBook 表格数据 
→ BoardCase 标准化案例 
→ 四类角色按信息边界做判断 
→ 多轮董事会辩论 
→ 最终结果聚合 
→ 与真实结果进行初步比较
 
目前核心价值：实验框架已跑通，能够产生可审计、可解释的角色推理过程。
 
下一阶段提高实验可信度：改善缺失值下的判断、增强辩论中的立场变化、建立批量评测指标。

## 六、存在的问题和个人思考

- 数据完整度相对不足。这会导致 Agent 在信息不足时倾向于给出较保守或模板化的判断，影响模拟结果的准确性。
- 后续不仅要关注角色是否符合设定，还要关注其对具体融资事件的判断是否合理。现实中的董事会决策会受到公司阶段、市场环境、融资压力、投资人结构等多种因素影响。同一角色在不同情境下可能会做出不同选择，仅从通用规则和表格中部分的可见信息进行模拟可能不够精细，需要进一步增强 Agent 的情境化决策能力。
- 当前辩论过程仍偏浅，更多体现为观点陈述，而非**充分的谈判和博弈**。后续可以围绕融资额、估值、控制权、投资人权利和 CEO 去留等关键变量，增强角色之间的让步、妥协和方案调整。
- 是否可以考虑引入金融、法律和公司治理等领域知识，作为角色判断和辩论过程的辅助依据？这可能有助于提升模拟过程的专业性、解释性和可信度。
